  Ingress is disabled. To access the API Gateway locally:

  export POD_NAME=$(kubectl get pods -n {{ $ns }} \
    -l "app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/component=api-gateway" \
    -o jsonpath="{.items[0].metadata.name}")
  kubectl port-forward -n {{ $ns }} $POD_NAME 3001:3001

  Then open: http://localhost:3001/health

  To enable Ingress, upgrade with:
    helm upgrade {{ .Release.Name }} ./observex \
      --set ingress.enabled=true \
      --set global.domain=observex.example.com \
      --set ingress.tls.enabled=true \
      --set ingress.annotations."cert-manager\.io/cluster-issuer"=letsencrypt-prod
